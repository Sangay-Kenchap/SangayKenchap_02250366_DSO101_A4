## Project Overview

This project demonstrates the deployment of a simple web application using GitHub, GitHub Actions, and Render. The goal was to automate the deployment process through a basic CI/CD pipeline.

## Steps Taken

### 1. Created the Web Application

* Developed a simple web application.
* Verified that the application runs correctly on the local machine.

### 2. GitHub Repository Setup

* Created a GitHub repository.
* Initialized Git and pushed the project files to GitHub.

### 3. GitHub Actions Configuration

* Created a workflow file: `.github/workflows/deploy.yml`
* Configured the workflow to run automatically whenever code is pushed to the `main` branch.

### 4. Deployment on Render

* Connected the GitHub repository to Render.
* Created a Web Service/Static Site.
* Deployed the application successfully.
* Verified that the application was accessible through the generated Render URL.

## Challenges Faced

* Configuring deployment settings correctly in Render.
